# # 🛒 Django E-commerce Store

# A full-stack e-commerce platform built with Python and Django, featuring product management, shopping carts, and order processing.

# ## 🔥 Features
# - **Product Listings**: Dynamic product display from the database.
# - **Cart System**: Users can add, remove, and update quantities.
# - **Order Tracking**: Backend logic for processing customer orders.
# - **Admin Panel**: Manage products, users, and orders easily.

# ## 🛠️ Tech Stack
# - **Backend**: Django (Python)
# - **Database**: SQLite (Development)
# - **Frontend**: Django Template Engine, CSS

# ## ⚙️ How to Run
# 1. Create venv: `python -m venv venv`
# 2. Activate: `.\venv\Scripts\Activate.ps1`
# 3. Install dependencies: `pip install -r requirements.txt`
# 4. Run server: `python manage.py runserver`
